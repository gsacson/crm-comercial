Configurar CRM Comercial
Para conectar la app con Google Sheets y compartirla con tu equipo, seguí estos 4 pasos. Solo se hace una vez.
1
Crear el Google Sheet
Abrí sheets.new para crear una hoja nueva. Copiá el ID que aparece en la URL: docs.google.com/spreadsheets/d/ESTE-ES-EL-ID/edit
2
Abrir Apps Script
Desde el Sheet: Extensiones → Apps Script. Borrá el código que hay y pegá el contenido del archivo Code.gs. Completá la variable SHEET_ID con el ID del paso anterior.
3
Ejecutar setup y deployar
Primero ejecutá la función setupSheets() (botón ▶ Run). Luego: Implementar → Nueva implementación → Tipo: Aplicación web → Ejecutar como: Yo → Acceso: Cualquiera. Copiá la URL que aparece al final.
4
Pegar la URL acá
Ingresá la URL del Web App y tu nombre para identificarte en los registros.
